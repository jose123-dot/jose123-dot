## 🏗️ Infraestructura y Flujo de Trabajo

```bash
# Mi flujo típico en producción
$ git push origin main          # CI/CD via GitHub Actions
$ ssh user@vps                  # Linux VPS (Ubuntu)

$ docker logs -f app            # Monitoreo en tiempo real
```
